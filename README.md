# QA Manual Test Cases - SauceDemo

Documentação de testes manuais realizados no e-commerce de demonstração [SauceDemo](https://www.saucedemo.com/), como parte do meu portfólio de estudos em Quality Assurance.

## 📋 Conteúdo

- **[casos-de-teste.md](./casos-de-teste.md)** — 5 casos de teste manuais cobrindo login (sucesso, erro e usuário bloqueado), carrinho de compras e ordenação de produtos.
- **[bug-reports.md](./bug-reports.md)** — 3 relatórios de bugs identificados durante os testes, documentados no formato usado no mercado (severidade, prioridade, passos para reproduzir, resultado esperado x obtido).

## 🎯 Objetivo

Este projeto demonstra habilidades de teste manual: elaboração de casos de teste, identificação de bugs e documentação clara — complementando os projetos de automação do meu portfólio:

- [qa-api-postman-tests](https://github.com/maxrcj/qa-api-postman-tests) — testes de API com Postman
- [qa-cypress-web-tests](https://github.com/maxrcj/qa-cypress-web-tests) — testes E2E com Cypress

## 🛠️ Conceitos aplicados

- Estrutura de caso de teste (pré-condição, passos, resultado esperado, status)
- Classificação de bug por severidade x prioridade
- Documentação técnica em Markdown
